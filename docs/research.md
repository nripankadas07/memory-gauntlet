# Research notes

The project focuses on memory governance dimensions that ordinary recall-only
benchmarks can hide. Relevant background includes:

- [LongMemEval](https://github.com/xiaowu0162/LongMemEval), a long-term
  interactive-memory benchmark.
- [LoCoMo](https://github.com/snap-research/locomo), long-term conversational
  memory data and evaluation.
- [How Memory Management Impacts LLM Agents](https://arxiv.org/abs/2505.16067),
  which studies addition, deletion, stale experience, and error propagation.
- [OWASP Agentic Security Initiative](https://genai.owasp.org/initiatives/agentic-security-initiative/)
  for agent authorization and data-boundary risks.

Memory Gauntlet does not redistribute these datasets. Its scenarios and scoring
contract are original, small, synthetic, and fully offline.
